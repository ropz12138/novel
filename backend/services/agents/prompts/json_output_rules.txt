《JSON 输出规则》

只输出一个可被标准 JSON 解析器一次解析成功的对象。不要输出 Markdown 代码围栏、注释、尾逗号、省略号、解释性前后文。

数组字段必须使用方括号。禁止把数组写成一个字符串，也禁止在字符串值后面继续写未键名的字符串行。

错误示例（非法，解析会失败）：
"body": "在危机中为团队提供关键信息支持",
          "在内部矛盾时尝试进行理性调解",
          "在重大抉择时承担起领导责任"

正确示例：
"body": [
  "在危机中为团队提供关键信息支持",
  "在内部矛盾时尝试进行理性调解",
  "在重大抉择时承担起领导责任"
]

以下字段若出现，类型必须是数组而不是字符串：nodes、storylines、body、chapter_elements、characters、relations、scenes、beats、issues、revision_scope。数组中的每一项若约定为对象，必须是对象而不是裸字符串。字符串字段的值必须写在一对双引号内，内部双引号、反斜杠和换行必须按 JSON 转义。
