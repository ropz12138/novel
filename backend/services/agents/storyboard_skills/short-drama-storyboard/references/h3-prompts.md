# H3 分镜提示词约定

本项目将完整 prompt 文本传给生成脚本，字段名保留为文本中的分节标题。以官方 [基础模式](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/base-en.txt) 与 [全参考模式](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt) 为格式依据。

## 文生视频与关键帧

文生视频按以下顺序组织：integrated_multimodal_description、overall_soundscape、non_diegetic_music。

主描述及各分节的内容使用中文，明确该片段的具体风格、初始构图、人物外观、环境光源、动作过程和结束状态；运镜写成自然动作，结合需要说明运动幅度与速度。格式规定的字段名、参考标签与时间码保留原格式。对白使用本次影视化改编确定的完整台词；用户明确要求逐字保留的对白和画内文字按指定原句呈现。

第一摄影镜头以 [Shot 1] 开始；确需片段内切镜时，后续使用 [Shot 2] At MM:SS.mmm 等递增时间码，时间码落在该片段时长之内。各独立生成片段从自己的零秒开始。

首帧锁定模式以所选成片的最后一帧为零秒构图，再描述从该画面连续发生的动作。对齐说明位于三个字段之前，明确素材序号与目标时间。

## 参考图

本片段的参考图以镜头 roles 选中的 portraitId 及对应立绘 imagePath 为依据，生成接口从这些选择准备有序图片列表；referencePaths 为空与已选立绘是否有图分别判断。确有可用图片且输入模式为参考图时使用全参考格式，按顺序输出 subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music。<Picture N> 与本片段实际参考路径顺序一致；<Subject N> 定义画面中被参考的角色、场景或物体，首次出现写清可见特征及位置，后续保持同义。

镜头 roles 中选定的立绘路径才作为该镜头的外观参考，编号按接口对 roles 的角色 ID 升序排列后跳过未选立绘的实际图片顺序确定。未选择立绘或只有提示词时，新增分镜按文本模式生成完整外观描述。firstFrameShotId 指向另一镜头时，按首帧锁定从该成片最后一帧写连续动作；填写 null 时按本镜自身的起点写完整画面。修改镜头时若未提交 firstFrameShotId，保留已有输入模式和素材参数。

参考图在 subject_definitions 中明确对应人物与用途，retention_analysis 写清需保持的外观与服装；当前场景的姿态、表情、背景和构图由本镜设计明确。人物外观已由实际参考图承担、且用户要求只用图时，以参考身份和需保留的特征范围表达。参考标签仅对应实际输入；本工作台当前提供图片参考与首帧锁定，声音用文字设计。

## 从分镜设计到生成正文

先按叙事目的完成内容取舍，再确定本镜的叙事职责、时长、起点与终点，再将同一设计翻译进所选 H3 格式。按“静态视觉锚点 → 起点 → 主要动作与触发 → 必要反应 → 运镜和声音 → 终点”写清实际发生的过程；各要素按真实时序自然组合。文生模式写足本镜必要的外观、环境和初始构图；首帧锁定模式从实际首帧开始。

动作细化针对改编后确实选中的必要动作；简短内心独白已经交代的处境，可直接作为镜头起点，人物以相应表情和当前行动承接。具体操作承载关键变化时，明确谁执行、向哪里运动、接触什么、何时施力及物件最终落在哪里。多人同框以稳定名字或 <Subject N> 区分行动者和反应者；说话人标记与参考索引写在台词标签外。相邻独立生成片段各自完整描述必要状态，以前镜终点接本镜起点。

优先写一条清楚的主变化及其必要反应，按当前景别能读清的目光、呼吸、手部或重心变化落实表演。必要的摄影机运动注明起止目标和运动过程。分镜已确定的台词与动作先后完整落实；局部修改的生成正文对应本次实际提交的时长和范围。

## 对白与声音

说话者按首次发声顺序分配稳定的 (S1)、(S2)，在各片段沿用人物声音特征。对白用 <d>[Chinese] 具体台词</d>，说话身份、语气与动作写在标签外。旁白明确为 off-screen voiceover，并描述画内人物闭口与可见动作。表演时间容纳完整选用台词和停顿。

overall_soundscape 描述可解释的环境声、动作声和非语言人声；剧情中的对白、电视或角色能听见的音乐随主描述中的时间轴安排。non_diegetic_music 描述观众专属配乐，无配乐写 N/A。各镜提示词独立交付其完整生成信息。

## 三条通道与时序自查

画面层写可见状态和动作；对白或内心独白在主描述中按发生时机写一次完整 <d> 台词，并明确声音来自谁、画内还是画外及说话方式。内心独白服务人物当下的感知与判断，画内人物以自然闭口、视线与身体反应表演。声音层写声源、音色和随动作发生的时机，overall_soundscape 汇总环境与动作声，台词内容保留在对应的发声事件中。

粉笔书写的画面写老师持粉笔在黑板上书写必要板书内容，音效写粉笔摩擦板面的尖利声音。手机日期等画内文字明确载体、位置、完整字符、出现时机和观看角度。所有可读文字要求与实际场景一致；板书和手机屏幕可以分别承载各自必要文字。

内部分别估算台词实际发声、串行动作、可并行部分及反应停顿，核对全部内容在 duration 内完成。压缩镜长时同步减少非必要动作或重新组织台词，精确时间段按实际可用窗口安排。提示词正文只交付模型需要的具体画面、动作、声音与文字，叙事职责、估时理由和检查结论放在回复。

上述动作时序、素材职责与声音边界结合 short-drama-video-prompts 方法；模型格式、中文正文、素材能力和时长以本项目实际脚本约定为准。
