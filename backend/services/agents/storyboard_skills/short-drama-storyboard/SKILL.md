# 小说章节短剧分镜

## 输入与改编目标

完整阅读章节、角色、现有分镜和全部用户要求，在理解整章剧情后重新设计适合视频观看的分镜。章节提供剧情事实，镜头承担独立的视听叙事；从只看成片的观众视角，交代人物身份、处境、动机和冲突，使信息随着动作、画面和声音自然揭示。目标是将文学叙述改编为值得观看的戏：先确定本集的核心冲突、关键选择、认知变化或情绪回报，以及结尾悬念，再选择能承载这些内容的片段。原文字数与段落数量是理解材料的规模，镜头数量取决于有效戏剧内容。

常规一章约一千字的内容，以一至两分钟左右的成片节奏作为改编参考。先完成叙事取舍，再估算正常动作和对白需要的时间，让时长反映有价值的戏。实际长度服从章节戏剧密度与作者明确要求，镜头数随内容自然形成。局部修改按用户指定范围进行，整章重新提炼使用 replace_storyboard。

## 按叙事目的压缩铺垫（优先原则）

先提炼“这段小说最终交代了什么”，再决定短剧怎样直接让观众理解。核心剧情保持人物身份、关键事实、动机、选择、因果和结果；环境渲染、感官细节、用于证明同一认知的副动作以及文学性的认知路径，可按视听效率省略、合并或替换。小说的“铺垫 → 目的”可以改成短剧的“直接呈现目的 → 推进下一项剧情”。视听表演可以在一句台词的同时完成情绪与氛围建立。

为每组原文描写在内部归纳一个叙事目的，选择能让观众理解的最简有效表达：一个有意义的画面、一个反应、一句自然的内心独白或对白，或它们的简洁组合。目的已经成立时，进入人物的下一项选择、冲突或结果。只有铺垫本身另有独立剧情价值，如建立后续必须使用的道具、支撑关键推理或形成需要兑现的悬念，才单独保留。必要性检查针对所有新增观察、求证、环境和反应镜头进行。

改编示例：原文用闷热教室、粉笔声、抠裂桌角、查看年轻手掌和旧伤消失，共同说明男主重生。若这些细节的唯一作用是确认重生，可以直接用男主在教室惊醒的短暂惊讶，配合画外内心独白“我居然重生了”，随即进入他判断剩余时间或应对危机的行动。教室作为当前画面的环境存在。若桌角、手伤或其他证据另有后续作用，则按那个作用选择必要呈现。

以上是改编选择方法，具体表达随故事变化。人物可以在一个瞬间完成认知；认知过程承担关键悬念或冲突时，再展开观察与确认。先精简叙事内容，再对留下的镜头应用动作链、连续性和时长规则。完整阅读并保留输入全文与提示词的要求持续适用，省略发生在影视改编选择层。

## 判断是否值得独立成镜

为每个候选片段回答：它带来什么新的局势、信息、人物选择、关系变化、情绪回报或必要伏笔？如果省去它，观众会失去哪项关键理解或观看体验？能否由另一个已选片段的动作、道具、表情或声音同时承担？

有独特叙事作用、且需要独立画面才能充分成立的片段，进入分镜。与已选片段重复的信息归并呈现；连接性内容通过直接进入新场景、简短视觉线索或声音衔接处理。纯粹因为原文详细描写了某个动作、物件或环境而形成的候选，回到上述判断重新评估。

以整章核心剧情为依据重新组织呈现顺序，并沿实际事件因果串联成可理解的戏：重要决定有动机，危险有建立，结果有兑现，结尾留下明确变化。必要的停顿、反应与氛围可以保留，其观看作用与时长应清楚。人物关系、事件事实和作者明确指定内容保持成立，取舍在最终回复中简要交代。

## 先改编，再拆镜

1. 提炼观众必须理解的因果链：人物目的、关键选择、阻力、后果与结尾变化。开场尽早呈现反常、冲突或悬念，把主要表演时间留给决定和后果。
2. 以观众理解为目标重新设计信息揭示顺序，合并分散在多个段落中的情节，把必要前提放在观众需要它的时刻。允许补充建立镜头、人物反应和简短解释性对白来表达已有剧情中的身份、关系和动机；人物事实、关键因果与最终结果保持一致。将原文信息按叙事作用归并。重复情绪、同义心理、购买清单、穿戴步骤、步行和环境铺陈，可选一个有辨识度的动作承担其信息，其余由省略、声音承接或进入下一场景的明确起始状态衔接。重要道具、人物关系和转折仍有建立与兑现。
3. 同一空间里传达同一信息的副动作，先选择最简有效表达；确有必要共同呈现的动作，再放入同一片段，用自然运镜或景深变化引导注意。新的信息、关系、危险或状态变化才值得独立占用片段。对白与听者反应可以共用画面与声音时间。
4. 对白可为视频叙事重新组织，保留说话者、事实、意图和人物关系。作者明确要求逐字保留的台词完整写入；其余对白按剧情作用取舍、改写或补充，并在回复简要说明。心理活动按角色当下所见、所知和诉求转成具体表演，必要的内心独白表达即时念头，与认知进程和动作同步；观众理解所需的前提通过可见证据、声音或简短台词建立。背景叙述按当前剧情的实际需要逐步释放。
5. 逐片段核算可表演性。以起始状态、主要动作、结束状态组织；中文对白可按约每秒 4 字初估，给停顿和动作留出时间。复杂动作有足够发展时间。分镜偏长时，重新审视片段的独特叙事作用、重复信息与过场占比，维持自然语速和动作节奏。

## 分镜与连续性

工作台一条分镜代表一次独立视频生成片段。默认采用一个连续摄影镜头；确需内部切镜传递新信息时，在该片段提示词中使用 H3 的 [Shot N] 和片段内时间码。每个片段满足工作台 1–15 秒容量，时长由必要动作、完整发声、停顿与反应共同推导；片段总时长与内部时间轴一致。

每片段给出明确叙事作用，并在完整提示词中体现主体、动作变化、空间、光源、景别和主导运镜。角色身份、服装、道具持有状态与位置保持稳定；同场景保持光向、空间布局和视线轴线。相邻片段以动作、视线、道具状态、构图或声音交接，跳过的路程与时间在新场景开头交代清楚。

分镜依据整章剧情重新创作，完整提示词自包含。镜头交付聚焦视听设计、人物动作与观众理解。合并、压缩和重新组织发生在影视改编层，输入章节、用户要求、参考材料与提示词全文均完整保留。最终分镜说明片段数、累计时长、核心节拍和主要改编取舍。

角色立绘按作品保存，一个角色可以有多张。立绘提示词通过 get_portraits、insert_portraits、update_portraits 和 delete_portraits 读写，版本号使用立绘回执。Agent 提供完整中文立绘提示词，用户也可自行填写；用户在立绘设计区点击生成后，系统创建图片并保存结果路径。镜头 roles 里的 portraitId 只选用该角色已有立绘；未指定时填写 null。

## 镜头职责与观众知情

设计时在内部明确每镜结束后观众或人物新增的理解：发现证据、确认身份、理解动机、看清决定、感受关系变化或接住后果。景别与运镜按承载信息选择，手机数字需要能读清的取景，人物反应需要能看清表演的尺度，群体与空间关系需要足够的环境。摄影机移动写清从哪里开始、跟随什么、停在哪里，其速度与注意力转移吻合；固定机位同样可以承担完整叙事。

按观众已知事实、角色已知事实和本镜新证据安排揭示顺序。重生或惊醒场景可以通过一次当下反应与简短内心独白直接确认处境；只有观察求证另有悬念、冲突或转折价值时，才展开其过程。后果通过受影响人物的反应、声音或道具变化落地。每次切镜带来必要的信息、空间、情绪或关系变化；相邻镜头复核同一关键动作已经完成到哪一步，下一镜承接其结果。

## 可执行动作与时长

动作链仅落实改编后选中的必要内容；可直接从已成立的处境或结果开始，具体操作在承载关键变化时展开。为每条生成片段在内部建立“起点 → 主要动作 → 终点”：起点交代人物位置、身体朝向、视线、双手与持物；主要动作明确触发、方向、接触、施力及落点；终点给出可观察的结果，并能作为下一镜可信的起点。必要的副动作服务主要变化。触碰、递交、换手、放下、取回分别说明执行者和物件落点，双手任务按先后或合理并行安排。例如红笔写出“15:00”需要有笔尖接触纸面并写成数字的动作。

先核算完整对白与独白的发声窗口，再安排互为前提的动作、换气、停顿和末尾反应。中文约每秒 4 字仅作起算，按数字、日期的实际读法及角色语速调整；迟疑、惊讶和气声需要相应停顿。说话、轻微抬眼、环境声和运镜可以合理并行，取物后才能操作等串行动作保留先后。时间不足时先精简非必要动作和重复信息，再按可见状态闭合点拆镜或调整时长，保持自然表演。

显式时间轴从片段零秒排到 duration，逐段核对动作和发声是否装得下。总结中的时长与修改效果以实际提交字段和工具回执为准。

## 空间与跨镜连续性

同场景先在内部确定桌沿、门窗、黑板等固定锚点，人物相对位置、朝向、视线轴线、摄影机工作侧和光源方向。逐镜把这些空间事实换算为当前机位的画面位置；转机位时保留世界空间中的关系。需要同时看到手机屏幕与人物表情时安排实际可行的屏幕朝向和机位，或分别交代证据与反应。

检查上一镜终点与下一镜起点的人物、双手、持物、伤痕、服装、光向和道具状态。跳过时间或路程时，在新场景起点给出足以理解的变化。局部修订保留有效镜头 ID；只有本次要求涉及的字段和必要衔接发生变化，下游已有视频与新提示词的关系在回复中说明。

## 完成前内部核对

- 先检查同一叙事目的能否由一个反应或一句台词直接成立，将仅用于重复证明的铺垫归并或省略，再核对每镜的叙事职责、观众理解和人物认知进程成立，主要冲突、动机、关键选择与结果形成可理解的剧情链。
- 每镜有清楚的起点、主要动作、终点；手部任务、道具接触、视线、取景与前后状态可执行。
- 发声、动作和反应的实际时间落在片段时长内，显式时间轴和 duration 对齐，全章时长依据本次最终分镜求和。
- 画面、对白、内心独白、环境声与画内文字各有明确归属，交付 prompt 采用正向表达；内部检查结论和设计理由放在回复而非生成正文。
- 保存工具回执确认本轮实际修改范围后，简洁说明完成内容和改编取舍。

## H3 提示词

完整读取 [H3 提示词约定](references/h3-prompts.md)，按实际素材选择格式。已有素材路径与输入模式决定可使用的参考标签。整章设计通过 replace_storyboard 保存，并为每个镜头填写 firstFrameShotId，指向本章另一镜头或填写 null。局部提示词修改通过 update_shots 仅提交 id 和 prompt，其他字段保持原样。新增、删除和排序分别使用对应工具。每批保存后继续完成其余工作，最后单独调用 finish_turn 回复用户。媒体生成由用户在分镜区触发。
