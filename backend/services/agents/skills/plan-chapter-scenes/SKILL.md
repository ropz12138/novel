# 章节与场景规划

Supervisor 在当前上下文亲自规划，通过 `read_skill_reference` 完整加载 `scene_plan.txt`。本技能的产出是当前任务中的故事设计；正文由独立 Writer 在设计边界内创作。适用于写章前、作者单独要求场景规划，以及修订中需要改变场景设计的任务。

## 创作参考前置

新内容设计与创作的必经环节是参考研究。Supervisor 先确定范围、目标体验及作者约束，工具集中有 `run_reference_agent` 时，本轮实际调用它。取回章节原文后完成本作化，再形成具体方案，由你完成设计并将写作材料完整交接给 Writer。作者已有完整方案时，检索围绕其已确认内容取回相关章节原文。本轮未取回章节原文时，按当前作品已有事实、作者已确认的事件与设定完成本轮方案与正文。同一轮同一范围沿用本轮已取得的完整结果，扩大范围或改变核心方向时重新研究。取回原文时，将真实作品与章节来源、选择理由和适配方式写入当前任务记录及需要持久保存的完整设计。

## 输入与范围

沿用已读取的完整作者要求、相关前章正文与笔记、人物、世界观和作品规划笔记。结合来源章节核对当前状态及正文已经建立的读者期待，区分有效作者决定、已发生事实和待写计划。根据请求确定本次章节或场景范围；涉及作者既定剧情取舍的冲突时，向作者确认。

## 规划流程

1. 明确本章承接的期待、主要回报、有效阻力与结束后的变化。根据具体作品的题材基调与相邻章节的张弛状态，判断本章应侧重主线攻坚、战后收获消化、世界风物与日常切片、支线奇遇还是主线与日常有机穿插，结合相邻章节安排铺垫、兑现、释放或关系发展，使本章承担适合当前位置的作用。
2. 按因果或体验脉络拆分场景，分别确定参与人物的目的、可用筹码、已知信息和阻力或驱动力。说明人物的行动如何引发对方应对，以及应对如何改变下一步选择。强者的阻力也可以来自信息、利益、时间和相互牵制的目标；对于日常切片、世界风物探索或收获消化等非攻坚场景，驱动力可来自好奇心探索、设定反差趣味、生活小摩擦或关系升温，不必强造外部敌对危机。
3. 确定关键选择、后果、信息释放时机及希望形成的阅读体验。按需选择一至两项适配的局部技巧，用具体作用说明选择理由；写正文时根据现场语境实现动作、对白、心理和节奏。
4. 自检每场戏带来的局势、关系或认知变化，检查回报与铺垫的关联，并与相邻章节比较冲突解决方式。为薄弱场景调整目标、阻力或选择；保留有价值的休整、情感消化与生活互动。
5. 在当前任务形成完整计划。需要跨会话延续时，将计划整理为紧凑的事件骨架合并到章节笔记的创作设计部分，完整保留作者要求、人物目的、关键选择与后果、必要信息来源和承接状态，明确标记为“计划”，保留其余有效条目。每项事件集中表达关键因果，同义信息合并，设计推演保留在当前任务记录中；使用已回读的正文哈希调用 `save_chapter_notes` 并回读。简明场景标题与目的一并写入章节笔记。
6. 写作任务将完整计划留在当前任务说明中，并通过 compose_chapter 完整交接给 Writer；事实、人物认知及完整作者要求按任务需要进入同一次写作。单独规划任务保存与回读计划后向作者报告，正文创作按作者的写作请求执行。

## 完成标准

计划能说明本章为什么值得阅读、阻力如何影响选择、回报如何成立，以及场景间如何承接。关键设计有当前作品依据，作者要求完整保留；写正文时保留足够的创作空间来形成具体文学表达。
