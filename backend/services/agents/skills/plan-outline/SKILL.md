# 规划总纲

本技能由 Supervisor 亲自执行。参考规则通过 `read_skill_reference` 按阶段完整加载，工具仅负责读取与保存。
参考文件中的结构化输出格式用于组织工作记录；正文使用节点工具保存，用户回复使用 `respond_to_user`。

## 创作参考前置

新内容设计与创作的必经环节是参考研究。Supervisor 先确定范围、目标体验及作者约束，工具集中有 `run_reference_agent` 时，本轮实际调用它。取回章节原文后完成本作化，再形成具体方案，并由你直接完成相应正文或设计。作者已有完整方案时，检索围绕其已确认内容取回相关章节原文。本轮未取回章节原文时，按当前作品已有事实、作者已确认的事件与设定完成本轮方案与正文。同一轮同一范围沿用本轮已取得的完整结果，扩大范围或改变核心方向时重新研究。取回原文时，将真实作品与章节来源、选择理由和适配方式写入当前任务记录及需要持久保存的完整设计。

## 完成标准

总纲具备核心承诺、主要矛盾、近景细化落点与中后期远景锚点，兼顾主线升级与非主线血肉空间，并与既有正文一致。

## 执行流程

1. 读取结构节点、相关章节和完整用户要求，明确 create、reverse、continue 或 revise 任务。若用户尚未确定终局目标或仅给出局部设定/场景片段，从既有亮点向外推导阶段目标与远景锚点。
2. 用 `read_skill_reference` 读取 `outline_plan.txt`，亲自组织因果与分卷方向，使近期卷具备可直观评估的具体名场面与体验回报，中后期保持清晰的矛盾升级与悬念锚点；反推任务以已有正文为事实。持久大纲以目标、关键经过和阶段结果组织紧凑条目，完整保留作者要求与关键因果，各层集中表达本层信息，具体细节放入对应下级节点。
3. 用 `create_node` 建立新的总纲/卷，`create_edge` 建立父子关系；首次写入使用 `update_node(mode="overwrite")` 保存完整内容，已有总纲或卷的局部修订使用 `update_node(mode="replace", replacements=[...])`，整体重构才使用 `mode="overwrite"`，并始终沿用已有 UUID。
4. 回读核对因果、升级、题材承诺、顺序和正文兼容性。
