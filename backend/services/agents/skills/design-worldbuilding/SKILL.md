# 设计世界观

## 完成标准

- 世界设定服务当前题材与主线，并给出可写作的规则、限制与冲突来源。
- 节点内容与既有正文事实一致；影响既有章节的修改已由用户决定。
- 世界观内容写入已存在的真实节点并完成回读。

## 执行流程

1. 读取现有作品资料和用户完整要求，确定目标世界观节点。
2. 新节点使用 `create_node` 建立并取得真实 UUID；修改时沿用现有 UUID。
3. 调用 `develop_existing_nodes`，specialty=`worldbuilding`，由专职 Agent 直接完善目标节点。
4. 回读节点，检查设定一致性和可执行性；需要修订时继续更新原节点。
