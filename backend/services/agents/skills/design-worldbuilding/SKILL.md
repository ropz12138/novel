# 设计世界观

本技能由 Supervisor 亲自执行。参考规则通过 `read_skill_reference` 按阶段完整加载，工具仅负责读取与保存。
参考文件中的结构化输出格式用于组织工作记录；正文使用节点工具保存，用户回复使用 `respond_to_user`。

## 创作参考前置

新内容设计与创作的必经环节是参考研究。Supervisor 先确定范围、目标体验及作者约束，工具集中有 `run_reference_agent` 时，本轮实际调用它。取回章节原文后完成本作化，再形成具体方案，由你完成设定与故事设计，章节正文通过 compose_chapter 完整交接给 Writer。作者已有完整方案时，检索围绕其已确认内容取回相关章节原文。本轮未取回章节原文时，按当前作品已有事实、作者已确认的事件与设定完成本轮方案与正文。同一轮同一范围沿用本轮已取得的完整结果，扩大范围或改变核心方向时重新研究。取回原文时，将真实作品与章节来源、选择理由和适配方式写入当前任务记录及需要持久保存的完整设计。

## 完成标准

世界规则服务主线且与既有事实兼容，同时具备鲜活的社会生态、日常风物与可触发的支线钩子；目标节点已保存和回读。

## 执行流程

1. 读取相关世界观、结构、既有正文和用户笔记，明确修改目标。当用户仅给出不完整世界观或局部设定片段时，先提炼其核心奇观或规则支点。
2. 用 `read_skill_reference` 读取 `worldbuilding.txt`，亲自补全规则、代价、边界和冲突来源，并向外衍生该规则下的社会生态、底层日常运作、民俗潜规则与可转化为非主线剧情的支线钩子。
3. 新设定用 `create_node`；已有设定写回原 UUID，局部调整 `content` 使用 `update_node(mode="replace", replacements=[...])`，整体重构才使用 `mode="overwrite"`。影响既有正文事实的变更先明确范围并取得用户决定。
4. 回读目标节点，核对规则可执行性和既有事实。
