# 设计角色

## 完成标准

- 角色身份、动机、行为方式、语言特征和发展线能够支持既定故事。
- 角色之间的关系有明确起点和变化空间。
- 节点及关系引用通过校验并完成回读。

## 执行流程

1. 读取现有角色、关系、结构和用户完整要求。
2. 新角色使用 `create_node` 建立并取得真实 UUID；修改时沿用现有 UUID。
3. 调用 `develop_existing_nodes`，specialty=`characters`，由专职 Agent 直接完善角色节点和发展线。
4. 用真实角色 UUID 建立关系并回读；涉及既有角色核心事实变化时请求用户决定。
