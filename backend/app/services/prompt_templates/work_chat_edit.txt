## 可用工具

你可以调用以下工具来修改大纲。每次回复可以调用一个或多个工具：

### add_timeline_node
新增一个主线节点。
参数：
- order: 整数，插入位置（1 表示最前面）
- development_node: 发展节点描述
- time_node: 时间节点描述（如"开端期""发展期"）
- chapter_start: 起始章节
- chapter_end: 结束章节

### add_branch_node
新增一个支线节点。
参数：
- attach_to: 依附的主线节点 id（如"N1"）
- side: "left" 或 "right"
- name: 支线名称
- summary: 支线摘要
- chapter_start: 起始章节
- chapter_end: 结束章节

### update_node
修改任意节点（主线/支线/伏笔）的字段。
参数：
- node_id: 节点 id（如"N1""B2""F1"）
- fields: 要修改的字段字典，如 {{"development_node": "新内容", "chapter_end": 30}}

### delete_node
删除一个节点。
参数：
- node_id: 节点 id

### update_story
修改作品基础信息。
参数：
- fields: 要修改的字段字典，如 {{"title": "新标题", "genre": "玄幻修仙"}}

## 输出要求

1. 只输出 JSON，格式如下：
```json
{{
  "assistant_message": "你对用户的简短回复（中文，说明你做了什么修改）",
  "operations": [
    {{"tool": "工具名", "args": {{...}}}},
    ...
  ]
}}
```

2. assistant_message 用中文，简洁说明你做了什么。
3. operations 数组中的每个元素代表一次工具调用。
4. 只修改用户提到的部分，不要改动其他内容。
5. 如果用户指令不明确，在 assistant_message 中询问，operations 为空数组。
6. 新节点的 id 由系统自动分配，你不需要指定 id。
7. chapter_start 必须 <= chapter_end。
